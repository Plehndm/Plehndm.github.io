A cross-platform mobile and web app that helps users find, join, and create real-world events matching their interests within a chosen radius or city. Built with React Native, Expo, TypeScript, and Supabase (March–June 2026), it combines an interest-based recommendation algorithm, map-based browsing, friend connections, group coordination, and post-event ratings, and ships to Android, iOS, and web from one codebase.

## Highlights

- Recommendation algorithm that matches events to users based on their stated interests, with real-time notifications for matching events nearby
- Single codebase deployed to iOS, Android, and Web via React Native and Expo Go
- Supabase backend for authentication, data storage, Edge Functions, and PostgreSQL
- Social layer: friend connections, group chats, event coordination, and post-event ratings
- Privacy-first design with granular location controls, age verification, and safety features
- Zustand state management, documented architecture, and Jest test coverage reporting
